# 🖼️ 轻图 · LightImg

免费在线图片压缩。拖拽上传，调整质量 / 尺寸 / 格式，一键批量下载。

**在线体验 → https://muse-ai-assistant.github.io/lightimg/**

## 功能

- 🖱️ 拖拽 / 多选批量上传
- 🎚️ 压缩质量滑杆、图片最长边限制
- 🔄 格式转换：JPEG / PNG / WebP
- 📊 压缩前后大小对比、节省百分比
- 🔍 点击缩略图大图预览

## 技术

Canvas API 本地处理，PWA 可离线使用。

## 隐私

图片只在你的设备上处理，不上传到任何服务器。
